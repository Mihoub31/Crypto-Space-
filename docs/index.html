# Ledgerline Ledgerline is a crypto news and market dashboard built as a static frontend with a lightweight Node.js backend for the customer room. ## Features - Dark mode toggle - Market snapshot with live-style cards - Sortable and filterable top-gainers table - Momentum chart widgets - Community chat room with persistent backend storage - Deployment-ready Express server serving the static site ## Run locally ```bash npm install npm start ``` Then open `http://localhost:3000` in the browser. ## Project structure - `docs/` — static frontend assets - `server.js` — Express backend and static hosting - `data/chat-room.json` — persisted customer room messages - `package.json` — Node project setup ## Deployment This project is ready to deploy to any Node-friendly host such as Render, Railway, Fly.io, or a VPS. } n
